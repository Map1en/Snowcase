# Snowcase

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja-JP.md) | 한국어

BOOTH에서 산 에셋은 물론, PC에 있는 패키지나 다른 사이트에서 산 아이템까지 한곳에서 관리하는 로컬 도구입니다. 패키지 안에 뭐가 들었는지 바로 보이고, 어디서 샀는지, 어떤 아바타에 썼는지도 기록해 둘 수 있습니다. 안 쓰는 건 깔끔하게 정리하세요. 구매부터 아바타 커스텀, 업로드까지 AI가 VRChat 아바타 생활을 도와드립니다.

> **상태: 초기 개발 중입니다.** 아직 사용할 수 있는 버전은 없습니다.

## 예정된 기능

- **라이브러리**: BOOTH, 다른 스토어, 제작자 개인 사이트, 로컬 폴더까지. 어디서 구했든 모든 에셋을 한곳에 모아 관리합니다.
- **링크와 메모**: 에셋마다 구매 페이지, 메모, 태그를 남길 수 있습니다.
- **패키지 미리보기**: Unity를 열지 않아도 `.unitypackage` 안을 볼 수 있습니다. 이미지와 3D 모델도 확인 가능합니다.
- **상품 정보**: 상품 페이지에서 제목, 제작자, 이미지, 버전을 자동으로 불러옵니다.
- **이용 약관 확인**: VN3 라이선스를 읽고 공개 업로드나 재배포가 가능한지 등 주의할 점을 알려 드립니다.
- **사용 현황**: 어떤 에셋이 어느 Unity 프로젝트와 업로드한 아바타에 쓰였는지, 버전까지 확인할 수 있습니다.
- **VRCX-0 연동**: [VRCX-0](https://github.com/Map1en/VRCX-0)에서 아바타별로 사용한 에셋을 바로 볼 수 있습니다.
- **저장 공간 정리**: 같은 상품의 여러 버전도 중복 없이 저장해 용량을 아끼고, 안 쓰는 에셋은 보관하고, 주기적으로 정리합니다.
- **BOOTH 라이브러리 동기화**: BOOTH에서 구매한 아이템을 다운로드합니다.

모든 데이터는 사용자의 PC에만 저장됩니다. Snowcase는 에셋 파일을 업로드하거나 공유하지 않습니다.

## 지원 플랫폼

Windows를 먼저 지원하고, macOS와 Linux도 지원할 예정입니다.
