# Snowcase

[English](README.md) | 简体中文 | [日本語](README.ja-JP.md) | [한국어](README.ko-KR.md)

</div>

为 BOOTH 生态打造的本地资产管理器，硬盘里已有的包、在其他网站买的东西也能一起管。包里有什么一眼看清，从哪买的、用在哪个模型上都记得住，不用的东西收起来。从选购、改模到上传，AI 陪你玩转 VRChat 模型。

> **状态：早期开发中。** 目前还没有可用的版本。

## 计划功能

- **资产库**：BOOTH、其他商店、作者个人网站、本地文件夹，不管从哪来，都放在一起管。
- **链接与笔记**：每个资产都能记下来源页面、笔记和标签。
- **包预览**：不开 Unity 也能看 `.unitypackage` 里有什么，图片和 3D 模型都能看。
- **商品信息**：从商品页自动带出标题、作者、图片和版本。
- **规约检查**：读懂 VN3 规约，提醒你哪些不能公开上传、不能二次分发。
- **使用情况**：每个资产用在了哪些 Unity 项目、哪些已上传的模型上，用的哪个版本，一目了然。
- **VRCX-0 联动**：在 [VRCX-0](https://github.com/Map1en/VRCX-0) 里直接看到每个模型用了哪些资产。
- **空间整理**：同一商品的多个版本不重复占空间，不用的资产归档，还能定时整理。
- **BOOTH 库同步**：下载自己在 BOOTH 买过的商品。

数据都存在你自己的电脑上，Snowcase 不会上传或分享任何资产文件。

## 平台

先做 Windows，之后支持 macOS 和 Linux。
