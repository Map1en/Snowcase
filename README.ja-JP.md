# Snowcase

[English](README.md) | [简体中文](README.zh-CN.md) | 日本語 | [한국어](README.ko-KR.md)

</div>

BOOTH で買ったアセットを中心に、PC にあるパッケージや他のサイトで買ったアイテムもまとめて管理できるローカルツールです。パッケージの中身がすぐわかり、どこで買ったか、どのアバターに使っているかも記録できます。使わないものはしまっておきましょう。購入から改変、アップロードまで、AI が VRChat のアバターライフをまるごとサポートします。

> **ステータス：開発初期です。** まだ使える状態ではありません。

## 予定している機能

- **ライブラリ**：BOOTH、他のストア、作者の個人サイト、ローカルフォルダ。入手先を問わず、すべてのアセットをまとめて管理。
- **リンクとメモ**：アセットごとに購入ページ、メモ、タグを登録できます。
- **パッケージプレビュー**：Unity を開かなくても `.unitypackage` の中身を確認できます。画像や 3D モデルも表示。
- **商品情報**：商品ページからタイトル、作者、画像、バージョンを自動で取得。
- **利用規約チェック**：VN3 ライセンスを読み取り、公開アップロードや再配布ができるかなど、注意点をお知らせします。
- **使用状況**：どのアセットがどの Unity プロジェクトやアップロード済みアバターで使われているか、バージョンまで確認できます。
- **VRCX-0 連携**：[VRCX-0](https://github.com/Map1en/VRCX-0) で、アバターごとに使っているアセットを確認できます。
- **ストレージ整理**：同じ商品の複数バージョンも重複なく保存して容量を節約。使わないアセットのアーカイブや定期整理にも対応。
- **BOOTH ライブラリ同期**：BOOTH で購入したアイテムをダウンロード。

データはすべてお使いの PC に保存されます。Snowcase がアセットファイルをアップロード・共有することはありません。

## 対応プラットフォーム

まずは Windows 版から。macOS と Linux にも対応予定です。
